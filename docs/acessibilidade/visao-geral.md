# Acessibilidade: visão geral

O checklist do Grupo 08 combina quatro fontes, para que a inspeção de acessibilidade e a de usabilidade usem o mesmo roteiro.

| Fonte | Papel no checklist |
|---|---|
| **WCAG 2.2** (W3C) | Critérios de sucesso e níveis de conformidade (A, AA, AAA), citados pelos números entre colchetes. |
| **ABNT NBR 17225:2025** | Norma brasileira. Cada item indica a seção correspondente, como `NBR 5.2 – Imagens (5.2.1)`. |
| **Guia de Boas Práticas para Acessibilidade Digital** (UK–Brasil) | Orientações práticas, com a página de origem, como `Guia p.28`. |
| **Heurísticas de Nielsen** | Ligação de cada item com as heurísticas H1 a H10, com link para a [página de usabilidade](../usabilidade/heuristicas.md). |

As páginas 1 a 4 seguem os quatro princípios do WCAG. A página 5 trata da gestão do projeto. A página 6 reúne recomendações do Guia que a norma não exige, então a conformidade com a NBR não depende delas.

## Requisito ou recomendação

Segundo a NBR 17225, a conformidade **regular** exige todos os Requisitos (equivalente ao nível AA do WCAG). A conformidade **plena** exige também as Recomendações (nível AAA), com justificativa para o que não for atendido. Os itens marcados como `Recomendação` na linha de fonte não reprovam a conformidade regular.

## Recursos interativos

Em cada página de checklist, o topo mostra:

- **Progresso** da página, e o de cada seção ao lado do título.
- **Mostrar só pendentes**, para focar no que ainda falta inspecionar.
- **Copiar pendentes**, que copia a lista dos itens sem marca para colar nos [Resultados](../resultados/mercado-livre.md).
- **Limpar marcações**, para recomeçar a página.

!!! note "Onde ficam as marcações"
    As marcações são salvas no **navegador de quem está usando**, não no repositório. Cada integrante vê só as próprias. O registro oficial dos problemas fica na página de [Resultados](../resultados/mercado-livre.md).
